# Agent & AI Application Developer

**Agent / AI 应用开发与研发 · 行业场景应用 · 开源工具**

I build AI agents and applications for domain research, information analysis, and practical workflows.

我的工作聚焦于 Agent 与 AI 应用研发：从行业业务问题出发，把信息采集、研究分析与人工复核连接成可用的工作流。关注产业情报、A 股研究与邮件安全等场景，探索如何让 AI 输出有来源、可核验，并融入实际工作。

## Featured projects · 代表项目

### [MailGuard · 清邮](https://github.com/spikeHongg/mailguard-expert)

邮件安全研判工具，识别钓鱼、付款诈骗与提示注入等风险，提供原文证据及人工复核建议。支持 Agent Skill 与本地 HTTP API。

Email risk analysis with source evidence and human review, delivered as an agent skill and a local API.

### [China Stock Research Skills · A 股研究](https://github.com/spikeHongg/china-stock-research-skills)

面向 A 股研究的模块化 Agent Skills，覆盖业务、财务、行业、风险与估值，将公开资料整理为带来源引用的中文研究报告。

Composable agent skills for A-share research, with source citations and structured Chinese-language reports.

## R&D focus · 研发方向

- **Agent 工作流与工具集成**：将专业任务拆解为可组合的 Skills，连接模型、数据与工具。
- **行业研究与信息分析**：围绕产业情报和金融研究，组织公开信息、证据与分析过程。
- **可靠的 AI 应用**：重视来源追溯、输出校验、清晰的能力边界与人工复核。
- **AI 辅助开发**：把 Agent 融入编码、验证和文档流程，并分享实用的开发工具。
